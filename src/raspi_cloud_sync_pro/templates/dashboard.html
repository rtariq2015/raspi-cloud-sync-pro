rclone WebGUI
SSH tunnels required
Checking local administrator setup…
Separate local administrator setup and approval are required.
Opening this public dashboard on a phone does not create the two SSH tunnels needed on this browser’s computer. The GUI opens only at your own computer’s loopback address. Never publish the rclone administration port.
On an approved administrator computer, keep both SSH forwards running:
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:5573:127.0.0.1:5573 -L 127.0.0.1:5572:127.0.0.1:5572 pi@PI_HOST
Use the existing approved SSH account and private administrator credentials. This dashboard neither supplies credentials nor verifies your local tunnels.
